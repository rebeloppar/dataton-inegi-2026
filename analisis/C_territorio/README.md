# C_territorio

Territorio: regiones, serie histórica 2015-2025, futuro probable, ENIGH y ritmo por entidad. Los `00_extrae_*.py` preparan las bases de otros años y de la ENIGH.

Los scripts de R empiezan con `source("R/prep_endutih.R")` (ENDUTIH 2025) o leen un extracto de `datos/procesados/`. El orden para correrlos está en el [README principal](../../README.md#cómo-reproducir).
